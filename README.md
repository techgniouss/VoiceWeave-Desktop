# VoiceWeave Desktop

Windows dictation app: hold a key, speak into any app, get clean text. Offline speech models (Parakeet for English, IndicConformer for Telugu, Hindi and Tamil) and a small local cleanup model.

Status: early development. See `docs/superpowers/specs/` for the design and `docs/superpowers/plans/` for the build plan. Companion to the Android app, [VoiceWeave](https://github.com/techgniouss/VoiceWeave).

Build: install the .NET 10 SDK, then run `dotnet test desktop/VoiceWeave.slnx`.
